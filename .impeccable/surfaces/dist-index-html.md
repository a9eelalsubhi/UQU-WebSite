# Surface: portal shell + role entry (dist/index.html)

Mode: Operate (portal screens); the role-entry screen is the first impression for the dean and gets Persuade-level care inside the same world.
Audience/job: pick a role, then reach library, tickets, initiatives, reports fast. Constraints: keep all flows, RTL, offline, reduced motion, dark mode.

## Direction contract
THESIS: A clinical-grade portal that feels like a modern hospital information system with an academic soul: calm white work surfaces, a committed deep-teal rail, and one living element, the pulse. Refuses the template dashboard of numbered icon cards, English eyebrows and gradient hero tiles.
OWN-WORLD: cool clinical ground (#F3F6F6), white surfaces with hairline borders, deep teal rail (#06403D to #0A6B66), logo gold only for focus and the pulse highlight; Thmanyah Serif Display for headings, Readex Pro for UI text; 10/14px radii; soft offset shadows.
STORY: the dean sees a real, coherent college product, understands each role's space in seconds, and believes it can ship.
FIRST VIEWPORT: entry is a split screen; start side: logo, large serif title, one-line purpose, three role rows plus staff link; end side: a slowly rotating 3D point-cloud heart (canvas) with an ECG trace running beneath it. Role rows are the primary action.
FORM: pinned by user ("طبي حديث نظيف"); signature move = the heartbeat trace (entry scene, overview hero, route-change sweep under the topbar). seed: none (unavailable)
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
