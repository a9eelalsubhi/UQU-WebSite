# بوابة كلية الطب — UQU MedHub

نموذج تفاعلي لبوابة كلية الطب يضم مساحات للطالب وعضو هيئة التدريس والإدارة، ومكتبة للمحاضرات، والتذاكر، ولوحة متابعة المبادرات.

## التشغيل محليًا

افتح مجلد `dist` باستخدام خادم ملفات محلي، ثم افتح الرابط الذي يظهر في المتصفح. مثال باستخدام Node.js وأداة خادم ملفات من اختيارك. يحتاج عارض PDF إلى خادم HTTP، ولا يُنصح بفتح الملف مباشرة من نظام الملفات.

## ملاحظات

- يحتوي `dist` على ملفات الموقع الكاملة والمحاضرات المرفقة وأصول الخط وملفات عارض PDF.
- بيانات الطلبات والإعدادات التفاعلية محفوظة محليًا في متصفح كل مستخدم، والنموذج غير مرتبط بأنظمة الجامعة.
- توزيع المحاضرات على السنة الثانية تصنيف مبدئي للعرض.
- محتويات المستودع متاحة وفق إعدادات الوصول للمستودع.
